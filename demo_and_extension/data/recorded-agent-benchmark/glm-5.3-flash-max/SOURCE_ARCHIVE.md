# GLM chats with recorded reasoning

Local ZCode chat exports for completed NAUTILUS GLM scored runs 1, 2, and 3 only.

Each session contains a readable transcript and a structured JSON export. All stored reasoning, text, tool calls/results, and metadata are included. Screenshot attachments are copied alongside the chats. Available model request/response logs are included with transport headers and detected credentials removed.

The three completed scored runs are labeled explicitly; setup and interrupted attempts are excluded. This export cannot include provider-internal reasoning that was never exposed or saved.
